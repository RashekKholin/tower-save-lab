1. Keep your original

Make a backup of your current save before you edit it. The editor runs locally in your browser and downloads a separate file; it does not replace your game files.

2. Open your save

Open the save editor and choose a .sav file, drag it onto the upload area, or paste its encoded text. Once loaded, the editor starts in Resources.

On Windows, press Win + R and open this folder:

%USERPROFILE%\AppData\LocalLow\Fire Sword Studios\The Perfect Tower II\saves

3. Make focused changes

Choose a category or search for a setting. Enter a value or use an On/Off switch. The original value remains visible so you can compare. Use Undo to revert a single setting, or Undo all to start over.

Search works within the selected category. Select All fields to search the entire save. Technical paths are optional; turn them on when you need to identify a specific record.

4. Review and download

Select Review changes to inspect the before-and-after values. Download the edited .sav when you are ready. The editor checks that encoding and decoding preserve the edited bytes.

5. Try it in the game

Close the game before replacing its save. Keep your backup somewhere separate, then use the downloaded file as the replacement for the save you opened. Retain the original filename if replacing a file directly. Reopen the game and check the changes.

Know the limits

File-format verification is not a guarantee that every combination of game values will work. Unlocking a flag may require associated progress or rewards. Some custom records are preserved without ordinary editing controls; advanced byte editing is intended for users who know the format.

If a change does not behave as expected, restore your backup and try fewer edits at a time.
